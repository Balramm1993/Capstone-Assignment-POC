# GitHub Setup

This project is now connected to the GitHub repository `Balramm1993/Capstone-Assignment-POC`.

The repository uses the `main` branch. Changes can be published through the authorized GitHub connection.

For a local checkout:

```bash
git clone https://github.com/Balramm1993/Capstone-Assignment-POC.git
cd Capstone-Assignment-POC
python -m unittest discover -s tests
python agent.py
```
